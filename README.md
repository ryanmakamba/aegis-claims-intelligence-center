# Aegis Claims Intelligence Center

Recruiter-facing demonstration of explainable multi-line P&C claims analytics across Auto, Home, Commercial Property, Liability, and Workers' Compensation.

The application includes claims financials, reserve monitoring, fraud indicators, aging, leakage opportunities, a searchable claims register, and a prioritized intervention queue. All records are realistic synthetic demonstration data.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import the repository into Vercel using the Next.js preset and deploy from the `main` branch.
